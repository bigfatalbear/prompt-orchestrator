# Contribuindo

1. Faça fork e crie branch a partir de `main`.
2. Instale dependências com `npm install`.
3. Implemente seguindo a arquitetura em `ARCHITECTURE.md`.
4. Adicione testes para toda mudança de comportamento.
5. Rode `npm run lint`, `npm run typecheck`, `npm test` e `npm run build`.
6. Use Conventional Commits.
7. Abra PR descrevendo o que mudou e por quê.

Não adicione dependências sem justificativa. Não coloque regras de negócio em componentes visuais. Não exponha segredos.
